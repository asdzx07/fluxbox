网络与 TUN 透明代理栈

底层转发
国内直连不进内核 (零损耗 Bypass)
大陆 IP 集合在 TUN 路由层直接放行，流量不经过 sing-box 用户态，跑满千兆/万兆带宽
nftables 自动硬件级转发 (auto_redirect)
由 Linux 内核 nftables 高效劫持并透明转发局域网流量
TUN 激进吞吐模式 (MTU 65535 / GSO 硬件卸载)
将 TUN 虚拟网卡 MTU 设为 65535 并启用内核 GSO/GRO 分段卸载，大幅提升千兆/万兆测速吞吐；默认关闭（1500 安全兼容模式）
代理节点服务器 IP 强制直连
防止节点服务器自身握手流量产生回环死锁
屏蔽 QUIC 协议 (UDP 443)
阻断 HTTP/3 QUIC 流量，强制回退至更稳定、不易被运营商 QoS 限速的 TCP 链路
严格路由保护 (strict_route)
防止跨网络接口路由回环与隐性流量泄漏
流量协议嗅探 (SNI / Host)
精准提取 TLS/HTTP 首包域名以准确匹配分流规则
启用 IPv6 流量接管
接管并分流局域网 IPv6 流量（若宽带无原生 IPv6 建议关闭以防连接拖慢）
内核开机自启与进程守护
系统引导时自动启动 sing-box，异常崩溃时由守护进程即刻拉起

DNS 防污染分流与运行级别

防泄漏
海外代理域名启用 FakeIP
立即返回虚拟保留 IP，省去远程 DNS 往返等待，大幅加速网页首屏打开速度
国内外域名智能分流解析
国内域名走直连 DNS 拿最佳 CDN，海外域名走代理通道防 DNS 抢答污染
