# MyBox for Windows 官方风格桌面客户端

> **告别繁琐手动修改网卡固定 IP！** 在 Windows 保持主路由（如 `192.168.3.1`）DHCP 自动分配 IP 的前提下，打开桌面客户端即可一键接管/断开旁路由，并拥有 100% 深度复刻 **sing-box 官方客户端** 的极简桌面控制台体验。

---

## 🌟 核心特性与设计

1. **正规 Windows 原生程序（`MyBox.exe`）**：
   - 采用标准 C# 编译出的原生桌面程序，内置管理员提权清单（`requireAdministrator`）与高清应用图标；
   - **完全没有黑色的 CMD/PowerShell 控制台黑框**；
   - 桌面已自动创建 **`MyBox 旁路由客户端.lnk`** 快捷方式，双击直接运行！

2. **100% 还原 sing-box 客户端顶部胶囊开关逻辑**：
   - **打开客户端默认不修改网络**：保持主路由自动分配的 IP 与网络连接不变，正常上网无打扰；
   - **顶部胶囊（未连接状态）**：显示三角形播放按钮（`▶`）；
   - **点击连接**：系统自动将网关与首选 DNS 指向旁路由，胶囊变绿并实时显示连接计时（如 `1:25`）与正方形停止方块（`■`），秒级畅通外网（Google/YouTube）；
   - **再次点击断开**：一秒恢复主路由直连（DHCP 自动获取 IP/DNS），计时停止清零，胶囊恢复为未连接三角形；
   - **支持随时反复开关切换**：无需重启客户端或网卡。

3. **系统托盘常驻与任务栏图标（NotifyIcon）**：
   - 任务栏与右下角系统托盘常驻显示应用图标（`app.ico`）；
   - **关闭按钮最小化**：【设置】面板默认开启「点击右上角关闭 (X) 按钮时最小化到系统托盘，不退出后台」；
   - **托盘左键/双击**：随时呼出/前置激活主界面；
   - **托盘右键菜单**：
     - `打开主界面`
     - `断开旁路由` / `一键连接旁路由`（实时感知当前连接状态）
     - `一键还原主路由网络 (DHCP)`
     - `退出 MyBox`（此时才彻底清理还原网络并退出所有后台进程）。

4. **支持自由输入与修改旁路由 IP 与密码**：
   - 在主界面**状态卡片**中，支持直接修改旁路由 IP 输入框（如 `192.168.3.2`）与管理密码；
   - 在**设置**面板中同样支持修改旁路由 IP、端口、密码与最小化偏好；
   - 修改后自动持久化保存至 `config.json`，下次启动依然有效。

5. **双重零残留网络安全守护**：
   - 无论是通过托盘右键退出、设置页退出、还是命令行 `--reset`，系统守护进程都会自动执行 `netsh ... source=dhcp` 彻底还原网络，零网络残留。

## 🖥 界面功能模块

| 模块 | 功能说明 |
| :--- | :--- |
| **仪表 (Overview)** | 顶部运行状态胶囊开关、上传/下载实时速率图表、旁路由 IP 快捷输入框、本机 IPv4、延迟检测、内核状态（运行中/版本号）、当前活动连接数 |
| **组 (Groups)** | 实时展示 MyBox 的所有节点出站组（自动测速组、手动选择组、节点卡片），直接点击即可切换节点 |
| **分流 (Routing)** | 实时同步目标分流规则（直连、拒绝、自动、手动等），下拉修改后点击「保存策略并应用」即时写入旁路由，支持一键重置为官方默认策略 |
| **连接 (Connections)** | 实时展示所有 TCP/UDP 活动连接、目标域名、端口、网络协议、匹配分流规则及完整转发链路，支持搜索框实时筛选与一键清空 |
| **设置 (Settings)** | 自定义旁路由 IP、端口、管理密码验证登录、一键在默认浏览器打开完整 Web 面板、一键还原网络及安全退出客户端 |

## 🚀 启动与使用方式

### 方式一：桌面快捷方式（最推荐）
直接双击桌面上的：
```text
MyBox 旁路由客户端.lnk
```

### 方式二：直接运行主程序
在 `windows-client` 目录下，直接双击：
```text
MyBox.exe
```

### 方式三：命令行快速还原网络
若在极端异常情况下需手动一键恢复 Windows 默认网络：
```powershell
.\MyBox.exe --reset
```
或直接双击目录下的 `一键断开并还原网络.bat`。

```text
+-----------------------------------------------------------------+
|                       MyBox.exe (Windows 桌面客户端)              |
|                                                                 |
|   [ sing-box 原生风格视窗 ] (Edge App 独立应用模式，无多余边框)      |
|                 | (Fetch / WebSocket)                           |
|                 v                                               |
|   [ 本地守护伴侣微服务 ] (127.0.0.1:3038)                         |
|     |-- 网络网关控制: netsh 物理网卡级网关 & DNS 切换 / DHCP 还原  |
|     |-- 心跳保活守护: 窗口关闭时自动恢复网络，零网络配置残留       |
|     `-- 旁路由反向代理: /remote-api/*  --->  192.168.3.2:3036    |
+-----------------------------------------------------------------+
                                  |
                                  | (局域网 HTTP API)
                                  v
+-----------------------------------------------------------------+
|                  旁路由 MyBox (如 192.168.3.2:3036)               |
|                                                                 |
|   [ sing-box 内核 ] (Fake-IP DNS 7853 / TProxy 智能分流代理)    |
|   [ MyBox 后端管理 API ] (/api/status, /api/groups, /api/policies)|
+-----------------------------------------------------------------+
```

## 从源码构建启动器

构建环境：Windows 10/11、Visual Studio Build Tools（MSBuild）和 .NET Framework 4.8 Developer Pack。项目不依赖第三方 NuGet 包。

在此目录运行：

```bat
build.cmd
```

构建产物位于 `build\Release\MyBox.exe`。项目会同时复制 `core/`、`ui/`、图标、网络恢复脚本和由 `config.example.json` 生成的默认 `config.json`；发布时应将这些文件与 `MyBox.exe` 一起打包。示例配置不包含旁路由密码或会话 Cookie；客户端运行后产生的 `config.json` 属于本地凭据文件，已在 `.gitignore` 中排除，不要提交到仓库。
