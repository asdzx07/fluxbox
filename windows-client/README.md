# MyBox for Windows 桌面伴侣客户端

> **告别繁琐改网卡固定 IP！** 在 Windows 保持主路由（`192.168.3.1`）DHCP 自动分配 IP 的前提下，一键接管/断开旁路由，并拥有像素级复刻官方 **sing-box** 的极简桌面控制台。

---

## 🌟 为什么做这个客户端？

### 传统旁路由的痛点：
在家庭或办公局域网中，主路由通常负责 DHCP 自动下发 IP（网关为 `192.168.3.1`）。如果 Windows 电脑想要走旁路由分流，传统做法是：
1. 打开「控制面板」或「网络连接属性」；
2. 找到 IPv4 属性，从“自动获取 IP”改为“使用下面的 IP 地址”；
3. 手动填写 IP、子网掩码、把默认网关和 DNS 改成旁路由 `192.168.3.2`；
4. 当旁路由重启、维护或不需要翻墙直连主路由时，又得再进一遍设置改回自动获取。

### 本客户端的解决方案：
- **网卡无需改动**：本地网卡**永久保持主路由 DHCP 自动获取 IP 模式**！
- **秒级无感接管**：打开本应用即自动添加一条高优先级临时路由（Metric=5）并将 DNS 临时指向旁路由 `192.168.3.2`，流量瞬间走旁路由分流！
- **秒级彻底还原**：点击断开或退出应用，自动删除临时路由并恢复 DNS 为自动获取，100% 干净回退到主路由直连。
- **免浏览器，原生桌面体验**：借助 Windows 自带 Edge 运行时以独立无边框应用窗口（Edge App Mode）启动，无多余地址栏和插件干扰，享受媲美官方客户端的丝滑体验。

## 🖥 界面功能 (深度复刻 sing-box 风格)

1. **概述 (Overview)**：
   - 顶部状态胶囊：实时展示运行计时器与一键连接/断开按钮。
   - 实时流量动态折线图：每 2 秒同步旁路由 sing-box 内核的实时上行/下行速率与累计上传/下载流量。
   - 网络接口信息：当前物理网卡名称、本地 IP、旁路由 IP 及当前 Ping 往返延迟。

2. **组 (Groups)**：
   - 自动获取远程 MyBox 所有出站节点与选择组（如自动测速组、手动选择组、节点卡片）；
   - 支持直接在 Windows 客户端上一键点击切换出口节点，实时下发至旁路由内核生效。

3. **分流 (Routing)**：
   - 远程同步 MyBox 的目标分组分流规则（直连、拒绝、所有-自动、所有-手动、节点等）；
   - 在客户端直接修改下拉出口目标，点击「保存策略并应用」即刻写入旁路由并自动重新部署配置。

4. **连接 (Connections)**：
   - 实时查看旁路由正在处理的所有活动 TCP/UDP 连接；
   - 详细展示目标主机名/IP、目标端口、网络类型、源 IP、匹配分流规则、出口分流链路（如 `Li-reality → 所有-自动`）；
   - **支持连接搜索框**（实时模糊匹配主机名、规则或链路）与**一键清空全部活动连接**。

5. **设置 (Settings)**：
   - 自定义旁路由 IP（默认 `192.168.3.2`）与端口（默认 `3036`）；
   - 勾选「打开客户端时自动连上旁路由并接管流量」；
   - 提供「打开网页版面板」、「一键还原网络」与「退出应用」。

## 🚀 启动与使用方法

### 方式一：双击启动（推荐）
在 `windows-client` 目录下，直接双击运行：
```text
启动MyBox.bat
```
> **提示**：脚本内置了自动 UAC 管理员提权。启动时若弹出 Windows 用户账户控制窗口，点击「是」即可自动拉起桌面客户端视窗并接管流量。

### 方式二：网络快速还原
如果在紧急情况下需要彻底重置 Windows 网络，可直接双击运行：
```text
一键断开并还原网络.bat
```
该脚本会停止本地伴侣服务、清除临时路由、重置网卡 DNS 为 DHCP 自动获取并刷新 DNS 缓存。

## 🛠 系统原理架构

```text
+--------------------------------------------------------------+
|                    Windows 客户端 (本地电脑)                   |
|                                                              |
|  [ sing-box 风格 UI 视窗 ] (Edge App 原生单窗口模式)           |
|                |                                             |
|                v (Fetch API)                                 |
|  [ 本地 Node 伴侣服务 ] (127.0.0.1:3038)                     |
|    |-- 路由管理器: route add/delete 0.0.0.0 192.168.3.2      |
|    |-- DNS 管理器: Set-DnsClientServerAddress (自动切换/还原) |
|    `-- 反向代理: /remote-api/* ---> 192.168.3.2:3036/api/*   |
+--------------------------------------------------------------+
                               |
                               | (局域网 HTTP API)
                               v
+--------------------------------------------------------------+
|                     旁路由 (192.168.3.2)                      |
|                                                              |
|  [ MyBox 后端服务 (端口 3036) ]                              |
|    `-- sing-box 2.0 内核 (TProxy 旁路由透明代理与分流)        |
+--------------------------------------------------------------+
```
